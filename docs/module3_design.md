## 3.1 基本统计量设计

### 统计指标选择

本模块对6个水质参数分别计算四项基本统计量：

| 统计量 | 意义             | 在水产养殖中的应用         |
| ------ | ---------------- | -------------------------- |
| 均值   | 了解正常水质水平 | 建立养殖基地的水质基线     |
| 最大值 | 识别历史极端事件 | 如暴雨导致的盐度骤降高峰   |
| 最小值 | 识别极低事件     | 如凌晨溶解氧最低点         |
| 标准差 | 量化参数稳定性   | 标准差大可预警环境剧烈波动 |

### 算法实现

四项统计量均采用单遍遍历算法，时间复杂度 O(n)：

- **均值**：累加求和后除以样本数
- **最大值/最小值**：遍历比较，记录极值
- **标准差**：先求均值，再计算方差平方和，最后 `sqrt()`

仅统计 `valid == true` 的记录，确保分析对象为清洗后的高质量数据。

### 输出格式

统计结果以 CSV 格式写入 `reports/statistics_report.csv`，包含表头行：

```csv
参数,均值,最大值,最小值,标准差
Temp,25.6123,32.5000,15.2000,2.3456
Salinity,34.1234,40.5000,25.0000,3.4567
...
```

## 3.2 分段统计设计

### 3.2.1 凌晨缺氧预警

#### 背景

溶解氧的最低值通常出现在凌晨（日出前），此时水生植物不进行光合作用，反而在呼吸耗氧。如果凌晨 DO 均值低于 3-4 mg/L，对虾容易缺氧死亡。

#### 数据筛选策略

- 数据从 `2025-01-01 12:00` 开始，每5分钟一条
- 按日期分组（提取时间戳前10个字符 `YYYY-MM-DD`）
- 每天筛选 03:00 至 04:55 共 24 条记录（每5分钟一条：03:00, 03:05, ..., 04:55）
- 求当日凌晨 DO 均值

#### 预警分级

| DO 均值        | 预警等级     | 处理建议                   |
| -------------- | ------------ | -------------------------- |
| ≥ 4.0 mg/L    | 正常         | —                         |
| 3.0 ~ 4.0 mg/L | 亚缺氧预警   | 建议开启底部增氧机         |
| < 3.0 mg/L     | 严重缺氧预警 | 需立即投放颗粒氧并减少投喂 |

#### 算法流程

```
遍历所有记录（顺序读取，按天分组）
  ├─ 提取当前日期
  ├─ 收集该日期内所有 03:00-05:00 的 DO 值
  ├─ 计算当日凌晨 DO 均值
  ├─ DO_mean < 3.0 → 严重缺氧预警 → 写入 CSV
  └─ DO_mean < 4.0 → 亚缺氧预警 → 写入 CSV
```

### 3.2.2 盐度突变预警

#### 背景

暴雨或换水会导致盐度骤降，对虾是变温动物，盐度突降会引发渗透压应激反应，严重时导致大规模死亡。

#### 1小时变化率检测（基于真实时间戳）

- 公式：`|盐度(t) − 盐度(t−60min)|`，其中 `t−60min` 为约1小时前的记录
- 阈值：变化量 > 2 PSU → 触发预警
- 算法：双指针滑动窗口法
  - 外层指针 `i` 扫描每条记录
  - 内层指针 `prev` 追赶，使用 `timestamp_to_minutes()` 将时间戳解析为 epoch 分钟数
  - 当 `gap = t_cur − t_prev` 落在 [55, 65] 分钟区间时，比较两条记录的盐度值
  - 容差 ±5 分钟以适应数据采样时间和可能的微小偏差
- 优点：不依赖固定索引偏移（12条记录），即使有记录的增/删操作，仍能准确找到约1小时前的时间点

#### 24小时累计降幅检测（按日历日期分组）

- 使用 `extract_date()` 提取 YYYY-MM-DD 按天分组
- 计算每天窗口内盐度的 max − min
- 阈值：降幅 > 5 PSU → 触发预警

#### 为什么按日历日期做24小时窗口？

与缺氧预警采用一致的按天分组策略，具有以下优势：
- **鲁棒性**：不依赖固定288条一批，删除记录后不会导致分组错位
- **计算效率**：O(n) 单遍扫描，无需滑动窗口
- **精确性**：盐度日极差与24小时滑动窗口极差高度一致
- **跨日对齐**：日历日期分组自然处理每日边界，不会将不同天数据混在一起

## 3.3 皮尔逊相关系数分析

### 公式

单遍高效计算形式：

```
r = (n·Σxy − Σx·Σy) / √[(n·Σx² − (Σx)²) · (n·Σy² − (Σy)²)]
```

分子为协方差分子，分母为两变量标准差的分子的乘积。

### 数值稳定性

- 使用 `double` 精度，累加23,203条记录的平方项不会溢出
- 分母防零：若任一变量的方差为 0（常量），返回 `NAN`
- 对角元强制设为 1.0（变量与自身完全相关）

### 相关强度解释

| r 值范围  | 相关强度  |
| --------- | --------- |
| 0.8 ~ 1.0 | 极强相关  |
| 0.6 ~ 0.8 | 强相关    |
| 0.4 ~ 0.6 | 中等相关  |
| 0.2 ~ 0.4 | 弱相关    |
| 0.0 ~ 0.2 | 极弱/无关 |

### 特定参数对分析

根据任务书要求的四组参数对：

1. **水温 ↔ 溶解氧**：理论上呈负相关（水温升高→溶解氧降低）
2. **pH ↔ 溶解氧**：水体中两者受生物活动影响，通常呈正相关
3. **水温 ↔ 气温**：理论上呈强正相关（海温受气温直接影响）
4. **水温 ↔ 盐度**：受蒸发和降雨影响，通常呈负相关

### 输出格式

6×6 相关系数矩阵以 CSV 格式追加写入统计报告，行和列均标注参数名，可用 Excel 直接打开为清晰矩阵表。

    │
    ├── [3] 盐度突变预警 (3.2)

    │       ├── 找最强正/负相关
    │       ├── 分析四组特定参数对
    │       └── 输出到控制台 + reports/statistics_report.csv
