# 任务书要求

本项目依据《编程基础实践》任务书，开发一个海水养殖水质数据分析系统。

## 项目目标

- 运用 C 语言完成文件操作、动态内存、结构体设计等功能
- 处理时间序列水质数据：水温、盐度、pH、溶解氧、降水量、气温
- 实现数据预处理、异常检测、缺失值填充、滤波、统计分析、预测模型、备份恢复、权限控制等功能

## 核心模块

1. 数据基础操作
2. 数据预处理
3. 统计分析
4. 预测模型
5. 系统集成与用户权限管理

## 存储与报告

- `data/raw/`：原始 CSV 数据
- `data/processed/`：预处理后数据文件
- `backup/`：备份文件
- `reports/`：数据概览、统计报告、预警报告等
