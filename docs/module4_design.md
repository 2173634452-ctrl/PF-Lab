## 4.1 单因素线性回归预测模型

### 4.1.1 模型设计

#### 算法选择

采用**最小二乘法（Ordinary Least Squares, OLS）** 拟合线性回归模型：

```
DO = a × X + b
```

其中 X 为特征变量（默认 Air_temp），DO 为溶解氧（因变量）。

斜率 a 和截距 b 的计算公式：

```
a = (n·Σxy − Σx·Σy) / (n·Σx² − (Σx)²)
b = (Σy − a·Σx) / n
```

使用单遍累加法，O(n) 时间复杂度，避免存储中间结果。

#### 数据范围

仅使用 `valid == true` 的记录参与训练。NaN 值在 `extract_valid_pairs()` 阶段被过滤。

#### 防零除处理

当 `|denominator| < 1e-15` 时，表明自变量的方差接近零（如 Precip 预处理后几乎为常量），此时回归系数极不稳定，函数返回 `false` 并提示用户。

#### 为什么选择 Air_temp → DO 作为主模型？

气温与溶解氧之间存在物理机制关联：气温升高 → 水体表面温度上升 → 氧气溶解度下降。此外，气温数据较为稳定（传感器不易受水下环境干扰），适合作为预测因子。

### 4.1.2 模型评估设计

#### 评估方案一：决定系数 R²

对全部有效记录计算 R²，衡量模型整体的拟合优度：

```
R² = 1 − SS_res / SS_tot
```

其中：
- `SS_res = Σ(y_i − ŷ_i)²`（残差平方和）
- `SS_tot = Σ(y_i − ȳ)²`（总离差平方和）

R² ∈ [0, 1]，越接近 1 拟合越好。

#### 评估方案二：留出法（Hold-out）

按**时间顺序**切分数据集（不可随机打乱）：

| 部分 | 比例 | 用途 |
|------|------|------|
| 训练集 | 前 80% | 计算回归系数 a、b |
| 测试集 | 后 20% | 验证预测效果 |

评估指标为**均方根误差（RMSE）**：

```
RMSE = √(Σ(pred_i − actual_i)² / n)
```

RMSE 的单位与 DO 一致（mg/L），直观反映预测值与真实值的平均偏差。

#### 为什么按时间顺序切分而非随机？

水质监测数据是**时间序列**，具有时间自相关性。随机打乱会破坏时间结构，导致"用未来数据预测过去"的信息泄露，使评估结果过于乐观。80/20 前/后切分模拟真实场景：用历史数据训练，预测未来。

### 4.1.3 多因子探索设计

#### 探索因子

对以下 3 个因子分别建立单因素回归模型，比较 R²：

| 因子 | 参数 | 假设关系 |
|------|------|---------|
| 水温 | Temp | 水温↑ → DO↓（物理溶解度规律） |
| pH | pH | pH 受生物活动影响，与 DO 相关 |
| 盐度 | Salinity | 盐度↑ → DO↓（盐析效应） |

#### 排除因子的理由

**降水量（Precip）被排除**：预处理后 Precip 的方差 ≈ 0 (min≈0, max≈0.011, std≈0.0016)，几乎为常量。在 OLS 中，自变量方差趋零导致分母 `n·Σx² − (Σx)² → 0`，回归系数 β 极不稳定，微小的数据扰动就会导致 a、b 剧烈变化。因此 Precip 不适合作为回归自变量。

**气温（Air_temp）**：已在 4.1.1 中单独训练并评估，不重复比较。

#### 最佳因子判断

比较 3 个模型的 R² 值，R² 最高的因子被认为对 DO 的影响最大（在单因素线性关系假设下）。

### 4.1.4 讨论分析

#### 单因素线性回归的局限性

1. **忽略多因子交互**：DO 受温度、盐度、pH、生物活动、水流等多因素协同影响，单因素模型仅捕捉一个维度的线性关系，解释力有限。

2. **线性假设**：真实环境中变量间可能存在非线性关系（如 DO 与温度呈指数衰减），线性模型无法捕捉这类特征。

3. **时间序列特性**：水质数据是时间序列，存在自相关和滞后效应（昨天的水温可能影响今天的 DO），静态回归模型不建模时间维度。

4. **预测精度受限**：当 R² < 0.4 时，说明单因素仅能解释不到 40% 的 DO 变异，预测结果仅供参考，不宜作为养殖决策的唯一依据。

5. **预处理依赖性**：回归模型对异常值和缺失值高度敏感，必须在预处理后的数据上运行。不同模型可能需要不同的预处理策略（如窗口大小选择）。

#### 改进方向（4.2 选做）

- **多元线性回归**：同时纳入多个因子，提高解释力
- **多项式回归**：引入 x²、x³ 项捕捉非线性关系
- **时间序列模型**：ARIMA、LSTM 等考虑时间依赖
- **加权回归**：对近期数据赋予更高权重

## 模块四程序流程

```
用户选择 [4] 预测分析
    │
    ├── [1] 单因素回归 (4.1.1)
    │       ├── 预处理检查 → 未处理则询问确认
    │       ├── 训练确认 → 用户 Y/N
    │       ├── train_linear_regression(dataset, PARAM_AIR_TEMP, &model)
    │       │     ├── extract_valid_pairs() → (Air_temp, DO) 数据对
    │       │     ├── least_squares_fit() → a, b
    │       │     ├── compute_r_squared() → R²
    │       │     └── 存入全局 g_model
    │       ├── 显示回归方程 + R²
    │       └── 交互预测循环（输入气温 → 输出预测DO，-999退出）
    │
    ├── [2] 模型评估 (4.1.2)
    │       ├── 检查 g_model.trained（未训练则报错）
    │       ├── 评估确认 → 用户 Y/N
    │       └── evaluate_regression_model()
    │             ├── 展示 R² + 拟合强度解读
    │             └── 留出法：前80%训练/后20%测试 → RMSE
    │
    ├── [3] 多因子探索 (4.1.3)
    │       ├── 预处理检查
    │       ├── 探索确认 → 用户 Y/N（列出因子 + 排除 Precip 说明）
    │       └── explore_multi_factor()
    │             ├── Temp → DO: least_squares_fit + R²
    │             ├── pH → DO: least_squares_fit + R²
    │             ├── Salinity → DO: least_squares_fit + R²
    │             └── 比较 R² → 输出最佳因子
    │
    ├── [4] 完整预测流程
    │       ├── 预处理检查
    │       ├── 流程确认 → 用户 Y/N（列出3步骤）
    │       └── run_full_prediction_pipeline()
    │             ├── Step 1: train_linear_regression (Air_temp → DO)
    │             ├── Step 2: evaluate_regression_model (R² + 留出法)
    │             ├── Step 3: explore_multi_factor (Temp/pH/Salinity)
    │             └── 写入 reports/prediction_report.csv
    │
    └── [0] 返回主菜单
```

## 附录：关键数据结构

### RegressionModel

```c
typedef struct {
    double a;           // 斜率
    double b;           // 截距
    double r_squared;   // 决定系数 R²
    double rmse;        // 留出法 RMSE
    bool trained;       // 是否已训练成功
    int feature_param;  // 所用特征 (ParamType)
} RegressionModel;
```

### 全局状态管理

```c
static RegressionModel g_model = {0.0, 0.0, NAN, NAN, false, PARAM_AIR_TEMP};
```

- `train_linear_regression()` 训练完成后自动更新 `g_model`
- `predict_do_from_air_temp()` 依赖 `g_model` 进行预测
- `get_regression_model()` 供 UI 层查询模型状态
- 模式与 `preprocess.c` 的 `g_stats` 一致

### CSV 输出格式

`reports/prediction_report.csv` 分为 4 个 section，各含独立表头，空行分隔：

1. **回归方程参数**：斜率 a、截距 b、R²、RMSE
2. **留出法详情**：评估方法、训练/测试样本数、RMSE
3. **多因子比较表**：因子、斜率 a、截距 b、R²（含 Air_temp 和排除说明）
4. **结论与局限性分析**：最佳预测因子、局限性讨论
