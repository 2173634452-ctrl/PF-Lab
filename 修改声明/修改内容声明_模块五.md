**`has_permission()` 修改详情**：

```c
// 修改前：系统级操作（清屏/退出）对访客不生效
bool has_permission(UserRole role, int feature) {
    if (role == ROLE_ADMIN) return true;
    if (role == ROLE_GUEST) return (feature == 5 || feature == 7);
    return false;
}

// 修改后：系统级操作对所有角色开放
bool has_permission(UserRole role, int feature) {
    if (role == ROLE_ADMIN) {
        return true;
    }
    /* 系统级操作（清屏、退出）对所有角色开放 */
    if (feature == 9 || feature == 0) {
        return true;
    }
    if (role == ROLE_GUEST) {
        return (feature == 5 || feature == 7);
    }
    return false;
}
```

修改理由：清屏（功能9）和退出（功能0）是系统交互操作，与数据安全无关，不应受角色限制。修改前访客登录后无法正常退出程序（虽然 `main()` 中的退出逻辑不经过 `has_permission`，但 `handle_menu_choice` 中 case 0 的处理需要权限放行以保持一致性）。

**新增辅助函数 `display_text_file()`**（`src/ui.c` 第617-640行）：

```c
static void display_text_file(const char *filepath, const char *title) {
    FILE *fp = fopen(filepath, "r");
    if (!fp) {
        printf("\n  [提示] %s 文件不存在 (%s)。\n", title, filepath);
        printf("  请先执行相应的分析功能生成报告。\n\n");
        return;   // 优雅降级，不中断程序
    }
    printf("\n┌──────────────── %s ────────────────┐\n", title);
    char line[1024];
    int line_count = 0;
    while (fgets(line, sizeof(line), fp) && line_count < 200) {
        size_t len = strlen(line);
        while (len > 0 && (line[len - 1] == '\n' || line[len - 1] == '\r'))
            line[--len] = '\0';   // 兼容 Windows/Linux 换行符
        printf("  %s\n", line);
        line_count++;
    }
    if (line_count >= 200) {
        printf("  ... (文件较长，仅显示前200行)\n");
    }
    printf("└──────────────────────────────────────────┘\n\n");
    fclose(fp);
}
```

**设计要点**：
- `static` 限定：函数仅在 `ui.c` 内使用，不污染全局命名空间
- 文件不存在时优雅降级，输出提示信息而非 `exit()` 或崩溃
- 200行上限：防止大文件刷屏淹没终端，超出时显示截断提示
- 换行符兼容：同时去除 `\n`（Linux）和 `\r`（Windows），确保跨平台输出一致
